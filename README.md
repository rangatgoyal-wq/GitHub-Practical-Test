# Personal Portfolio Website

## About the Project
This is a basic personal portfolio website developed as part of the Git and GitHub practical test.

The website presents personal information, technical skills, projects and contact details using HTML, CSS and JavaScript.

## Technologies Used
- **HTML5:** For creating the structure of the website.
- **CSS3:** For styling and designing the webpage.
- **JavaScript:** For adding basic functionality and interactivity.
- **Git:** For version control.
- **GitHub:** For hosting the project and managing code.

## Project Structure
- `index.html` – Main structure of the portfolio.
- `style.css` – Styling and layout.
- `script.js` – JavaScript functionality.
- `README.md` – Project documentation.

## Features
- Personal introduction
- About section
- Technical skills
- Projects section
- Contact information
- Navigation bar
- Footer
